An entry for the [One Line, One Laugh bounty](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3): one hilarious line of at most 200 characters, where the laugh lands on a surprise turn. Our line asks a GPS for the meaning of life — and gets turn-by-turn directions into regret and your thirties.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
